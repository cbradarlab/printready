# 幫我印好 PrintReady

把圖片、標籤、卡片與 PDF 準備成尺寸正確、排版正確、可以直接使用的檔案。

## PUBLIC V1 FINAL

- 免登入
- 圖片 / PDF / CSV / Excel 內容由瀏覽器本機處理
- 支援圖片尺寸排版、標籤／價格貼紙、證件照、卡片、大圖分頁、PDF 拼版、小冊子、格式轉換與 PDF 整理
- PDF / Excel 程式元件目前仍需要網路載入
