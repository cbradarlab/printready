🔄

影片／音樂轉檔

影片與音樂格式互轉，可輸出 MP4、MP3 等常見格式。MP3 可選 128 kbps（檔案較小）或 192 kbps（音質較好）。

💬

字幕

自動把影片或音訊裡的語音整理成字幕。可選最快的可開關字幕，或把目前字型、顏色與位置固定在影片上的永久字幕。

✂️

分割／合併

把長影片切成需要的片段，不要的段落可以取消；需要時再把片段或其他影片重新合併成 MP4。

📦

素材抽取

可從影片中抽出畫面圖片或 MP3 音訊；MP3 可選 128／192 kbps，圖片等多個素材會整理成 ZIP 下載。

🔊

MP3 音量調整

統一一首或多首 MP3 的播放音量，可快速選 89／95／100／105 dB，也能微調。使用 MP3Gain／ReplayGain 邏輯，不重新編碼，調整後另存新檔，不覆蓋原始 MP3。

第一次使用｜完整影音桌面版怎麼開？

1️⃣ 下載 ZIP按下方「下載 Windows RC3」。下載完成後，先把 ZIP 完整解壓縮，不要直接在 ZIP 裡開程式。
2️⃣ 打開桌面版進入解壓縮後的資料夾，雙擊下面這個檔案：PrintReady_Desktop_V1_RC3.exe
3️⃣ 放入影片開始使用開啟後就能直接轉檔、做字幕、分割／合併或抽取素材。處理結果會存回你的電腦。
這是免安裝的 Windows 桌面版。請保留整個解壓縮後的資料夾，不要只把執行檔單獨搬走。MP3 音量調整是另一個獨立的小工具，可從下方另外下載。

為什麼不是全部放在網頁裡？

純網頁處理大型影片時，速度、記憶體與瀏覽器限制會比較多。桌面工具可以直接使用你的電腦來處理，因此更適合長影片、永久字幕、大量轉檔與 MP3 音量調整。你需要多做的只有「下載一次、解壓縮、開啟程式」。

🛡️ 第一次開啟可能會看到 Windows 安全提示。 目前這些桌面工具沒有購買程式碼簽章，因此 Windows 可能跳出 SmartScreen。請確認是從本頁下載後，再選「其他資訊」→「仍要執行」；如果來源不是本頁，請不要執行。
