🎬 影音工具

為了讓長影片、字幕與轉檔跑得更快、更穩，影音工具使用 Windows 桌面版處理。影片不需要先上傳到網站，工作會在你的電腦本機完成。

先說清楚：這不是「打開網頁就直接處理影片」的線上版。
需要先下載一次 Windows 桌面版。這樣做是為了讓大型影片與字幕處理能直接使用你的電腦效能，不必把大檔案上傳到網路上。
🔄

影片／音樂轉檔

影片與音樂格式互轉，可輸出 MP4、MP3 等常見格式。MP3 可選 128 kbps（檔案較小）或 192 kbps（音質較好）。

💬

字幕

自動把影片或音訊裡的語音整理成字幕。可選最快的可開關字幕，或把目前字型、顏色與位置固定在影片上的永久字幕。

✂️

分割／合併

把長影片切成需要的片段，不要的段落可以取消；需要時再把片段或其他影片重新合併成 MP4。

📦

素材抽取

可從影片中抽出畫面圖片或 MP3 音訊；MP3 可選 128／192 kbps，圖片等多個素材會整理成 ZIP 下載。

第一次使用｜下載後怎麼開？

1️⃣ 下載 ZIP按下方「下載 Windows RC3」。下載完成後，先把 ZIP 完整解壓縮，不要直接在 ZIP 裡開程式。
2️⃣ 打開桌面版進入解壓縮後的資料夾，雙擊下面這個檔案：PrintReady_Desktop_V1_RC3.exe
3️⃣ 放入影片開始使用開啟後就能直接轉檔、做字幕、分割／合併或抽取素材。處理結果會存回你的電腦。
這是免安裝的 Windows 桌面版。請保留整個解壓縮後的資料夾，不要只把執行檔單獨搬走。

為什麼不是全部放在網頁裡？

純網頁處理大型影片時，速度、記憶體與瀏覽器限制會比較多。桌面版可以直接使用你的電腦來處理，因此更適合長影片、永久字幕與大量轉檔。你需要多做的只有「下載一次、解壓縮、開啟程式」。

🛡️ 第一次開啟可能會看到 Windows 安全提示。 目前版本沒有購買程式碼簽章，因此 Windows 可能跳出 SmartScreen。如果你是從本頁下載，而且檔名是 PrintReady_Desktop_V1_RC3.exe，可以選「其他資訊」→「仍要執行」。如果來源或檔名不一樣，請不要執行。
